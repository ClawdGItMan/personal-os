## Global Constraints

- **Design is LOCKED**: `design_handoff_personal_os/README.md` governs (ivy/porcelain spec-sheet bands, Manrope + Geist Mono, no cards, no blue, times always ink except dark-mode live-band times = accent). New UI (Settings, editors, empty states, chat) must be composed from existing primitives (`mobile/src/components/spec/*`, `useTheme() → {mode,c,t}`) — zero hardcoded colors, zero new fonts.
- **NATIVE RENDERING GOTCHAS** (verified on device): (1) never put `rgba()` in an SVG gradient `stopColor` — rn-svg drops the alpha on iOS; use `stopColor={hex} stopOpacity={n}` or a flat rgba `<View>` (see `Band.tsx`, palette token `bandWash`). (2) Never rely on native `TextInput` placeholder with custom fonts — render placeholder as a `<Text>` overlay (see `AskBar.tsx`).
- **Middleware gotcha**: `src/lib/supabase/middleware.ts` redirects unauthenticated requests to /login; only `/api/*` paths ending in `/sync` are exempt. Every new API route that authenticates via Bearer token MUST be added to the middleware exemption and covered by a unit test (Next middleware only runs in prod build — e2e with `next dev` cannot catch it).
- **Auth for mobile→API**: mobile sends `Authorization: Bearer <supabase access_token>`; server validates via `supabase.auth.getUser(jwt)` and runs all queries through an anon-key client bound to that JWT so RLS applies as the user. Service-role only in cron syncs (existing pattern).
- **Model**: assistant uses **`claude-sonnet-5`**. Model resolver: if `ANTHROPIC_API_KEY` env is set → `@ai-sdk/anthropic`; else AI SDK default gateway string `"anthropic/claude-sonnet-5"`. Never hardcode another model.
- **Mock-data policy**: mock fallbacks are REMOVED as each surface goes live. Loading = skeleton shimmer (existing `Shimmer`/opacity pulse pattern); no data = designed empty state; never silently show fake numbers.
- **DB**: additive migrations only, every new table gets the standard 4-policy RLS block (`auth.uid() = user_id`), migration files land in `supabase/migrations/`, applied to prod project `evpuwdkrypzugdgxtqak` via Supabase MCP, then regenerate `database.types.ts` into BOTH `src/lib/supabase/database.types.ts` and `mobile/src/lib/database.types.ts`.
- **Verification gates**: web = `npm run build && npm run lint && npm test` at repo root; mobile = `cd mobile && npx tsc --noEmit && npx expo export --platform ios --output-dir /tmp/expo-export-check`. UI tasks additionally verified by iOS-simulator screenshots (light + dark).
- **Commits**: conventional, authored `ClawdGItMan <clawdgitman@users.noreply.github.com>`, `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- **Money stays Plaid-ready, not Plaid-wired**: manual accounts/transactions v1; `plaid_account_id`/`source` columns already exist. No Plaid SDK.
- **12-hour times everywhere.** Timezone: use device-local dates for "today" boundaries (existing hook pattern).
- **No new heavy deps** without need. Approved additions: `ai`, `@ai-sdk/anthropic`, `zod` (web already has), `expo-calendar`, `expo-haptics`, `expo-notifications`. NOT approved: react-native-gesture-handler (PanResponder pattern exists), chart libs (SVG primitives exist), state libs.

Schemas (exact):

```sql
-- focus_sessions
create table public.focus_sessions (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references auth.users(id) on delete cascade,
  started_at timestamptz not null default now(),
  ended_at timestamptz,
  planned_minutes integer not null default 50,
  label text not null default 'Deep work',
  source text not null default 'manual' check (source in ('manual','assistant')),
  created_at timestamptz not null default now()
);
-- transactions
create table public.transactions (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references auth.users(id) on delete cascade,
  account_id uuid references public.finance_accounts(id) on delete set null,
  occurred_at timestamptz not null default now(),
  name text not null,
  amount numeric not null, -- positive = inflow, negative = outflow
  category text not null default '',
  method text not null default '' , -- CARD / ACH / WIRE / '' (ledger tag)
  source text not null default 'manual' check (source in ('manual','plaid','agent')),
  external_id text,
  created_at timestamptz not null default now()
);
-- budgets (monthly spend budget)
create table public.budgets (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references auth.users(id) on delete cascade,
  month date not null, -- first of month
  amount numeric not null,
  created_at timestamptz not null default now(),
  unique (user_id, month)
);
-- assistant_briefs (cached generated brief)
create table public.assistant_briefs (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references auth.users(id) on delete cascade,
  generated_at timestamptz not null default now(),
  brief jsonb not null default '{}'::jsonb
);
```

Every table: standard 4-policy RLS block exactly as in `supabase/migrations/20260527120002_create_tasks.sql`. Indexes: `focus_sessions (user_id, started_at desc)`, `transactions (user_id, occurred_at desc)`, `assistant_briefs (user_id, generated_at desc)`.
